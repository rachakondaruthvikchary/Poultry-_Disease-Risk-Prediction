## ❌ NOT WORKING?

### Won't start?
- Check Python: `python --version` (need 3.8+)
- Check Node: `node --version` (need 16+)
- Run: `VERIFY_SYSTEM.bat`

### Can't login?
- Try: test@test.com / test1234
- Check backend is running

### Port already in use?
- Find process: `netstat -ano | findstr :8000`
- Or use different ports

### Image prediction fails?
- Try clearer image
- Check model exists: `PoultryGuardAI/AI/models/poultry_cnn.keras`
