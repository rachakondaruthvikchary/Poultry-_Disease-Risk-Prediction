❓ WHAT IF IT STILL DOESN'T WORK
════════════════════════════════════════════════════════════════════

1. Check Backend window
   • Look for errors like "Port already in use"
   • Look for "ModuleNotFoundError"
   
2. Check Frontend window
   • Look for "npm" errors
   • Look for "Cannot find module"

3. Manual fixes:

   IF: "Port already in use"
   → Close other apps using port 3000 or 8000
   → Try QUICK_RUN.bat (auto-kills processes)

   IF: "ModuleNotFoundError"
   → Try: DIAGNOSE_AND_RUN.bat (auto-fixes)
   → Or manually: pip install -r requirements.txt

   IF: npm errors
   → Delete: PoultryGuardAI\Frontend\node_modules
   → Run: cd PoultryGuardAI\Frontend && npm install
   → Then: QUICK_RUN.bat

4. Last resort - Manual startup:

   Terminal 1:
   cd PoultryGuardAI\Backend
   python -m uvicorn app.main:app --host 0.0.0.0 --port 8000

   Terminal 2:
   cd PoultryGuardAI\Frontend
   npm run dev

   Then open: http://localhost:3000
