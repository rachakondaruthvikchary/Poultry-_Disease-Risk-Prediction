❓ TROUBLESHOOTING
────────────────────────────────────────────────────────────────────────────────

ISSUE: Won't start?
→ Run: VERIFY_SYSTEM.bat
→ Check Python: python --version (need 3.8+)
→ Check Node: node --version (need 16+)

ISSUE: Can't access http://localhost:3000?
→ Wait 15-20 seconds
→ Check backend is running
→ Try refreshing page

ISSUE: Port already in use?
→ Close other apps using port 3000 or 8000
→ Run: netstat -ano | findstr :3000

ISSUE: Image prediction not working?
→ Try different image
→ Check model exists: PoultryGuardAI/AI/models/poultry_cnn.keras
→ Check TensorFlow: pip install tensorflow
